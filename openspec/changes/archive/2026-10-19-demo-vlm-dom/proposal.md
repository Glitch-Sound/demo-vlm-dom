## 背景と現行業務フロー

1. 現在のリポジトリは Python 開発テンプレートであり、CLI は挨拶を表示するだけである。
2. 走行中の静止画像から他車の位置を抽出し、注視優先度を判断して結果を見比べる手段はまだない。
3. 本変更はデモを対象とするため、既存の業務運用や判断担当者は存在しない。

## 利用者と運用者

| 役割 | 利用場面 | 目的・必要な判断 |
| --- | --- | --- |
| デモ実行者 | 走行画像を用意し、ローカルでデモを実行する | 他車の位置と注視優先度を画像上で確認し、失敗した画像を把握する |
| デモ実行者 | 設定と実行環境を準備し、結果を確認する | モデルとの接続、画像ごとの処理結果、再実行の要否を判断する |

## 解決する課題

走行画像に写る他車について、画像から見える位置関係と注視優先度を一続きの操作で可視化できない。
また、一部の画像やモデル呼び出しが失敗したときに、成功した画像を残しながら失敗対象と原因を確認する仕組みがない。

## 変更後の業務フロー

1. デモ実行者が前方の走行風景を写した静止画像、モデルを提供する Ollama、接続・描画設定を用意する。
2. デモ実行者が `demo` コマンドを実行する。
3. 各画像を設定した推論用の最大寸法に収まるよう縮小し、画像に見える他車の矩形と自車の前方進路との位置関係を取得する。車両ごとの注視優先度を「高」「中」「低」または「判定不能」として扱う。
4. 推論用画像の矩形を元画像の座標に換算し、判定できた車両の枠を元画像に重ね、元画像と同じ寸法・形式で出力する。
   他車を検出しなかった画像も、枠を付けずに出力する。
5. 画像ごとの失敗はファイル名と原因を示して次の画像へ進む。
   デモ実行者は終了時の成功・失敗件数と処理時間を確認し、必要な画像だけを修正して再実行する。

## 対象範囲

### 対象

- 静止画像に写る自車以外の車両について、画像上の位置と前方進路との関係に基づく三段階の注視優先度を可視化する。
- 位置関係を判断できない車両、無効な矩形、車両がない画像を区別して扱う。
- ローカルの Ollama 上の VLM を空の `/api/generate`、DOM を固定の `/v1/systemone` 質問で事前ロードし、画像解析と車両判定に使用する。
- 推論用画像の最大幅・最大高さを設定可能にし、縦横比を維持して必要な場合だけ縮小する。
- 複数画像の継続処理、成功時の同名出力上書き、失敗の表示、設定可能な接続・描画条件を提供する。

### 対象外

- 動画入力、速度・車間距離の測定、将来の車線変更や衝突の予測は、静止画像だけでは確認できないため扱わない。
- 詳細な検出精度評価や運転支援としての利用は、今回のデモの目的に含めない。
- モデルのダウンロードと Ollama サーバーの起動は、デモ実行前の準備とする。

## 運用開始の受け入れ条件

- AC-001: `demo` コマンドで走行画像を処理し、すぐ前方の同車線車両は赤、前方近くの左右の車両は黄、離れた車両や反対車線の車両は青の矩形で示した画像を元画像と同じ寸法・形式で受け取れる。
- AC-002: 画像上の根拠が不足する車両や不正な矩形は描画されず、他車を検出しなかった画像は矩形なしで出力され、それぞれの結果を確認できる。
- AC-003: 画像ごとの接続・推論・入出力の失敗はファイル名と原因がコンソールに示され、残りの画像が処理される。失敗した画像の既存出力は上書きされず、成功した画像の同名出力は上書きされる。
- AC-004: VLM の空要求と DOM の固定質問による初回ロードを実際の車両推論と区別して確認でき、接続先、各タイムアウト、保持時間、推論用画像の最大幅・最大高さ、枠の太さと三色を設定できる。
- AC-005: Mac または Ubuntu の対象環境で実静止画を使った一連の実行結果、成功・失敗件数、処理時間を確認できる。未確認の対象 OS がある場合は検証範囲を明示する。

## 変更する能力

### 新規能力

- `driving-scene-annotation`: デモ実行者に、走行静止画像内の他車の注視優先度を可視化した画像と画像ごとの処理結果を提供する。

### 変更する既存能力

- なし。既存の規範的仕様はない。

## 影響範囲

- **利用者・業務**: 新しいデモコマンドと画像・設定の準備手順、結果と失敗の確認手順が加わる。
- **API・外部連携**: Ollama の画像解析と判定 API を使用する。既存の外部連携はない。
- **データ**: 出力画像は成功時に同名ファイルを上書きする。失敗した画像の出力は更新しない。
- **品質・運用**: モデルの初回ロード、タイムアウト、対象 OS での実静止画確認が必要となる。既存のテンプレート CLI 名と配布名はデモ用に見直す。
